## Compile and Run

Compile any program using a C++ compiler such as g++:

```bash
g++ path/to/file.cpp -o program
./program
```

On Windows, run the generated executable with:

```powershell
.\program.exe
```

Each source file contains an independent program and should be compiled separately.
